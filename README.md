# Block Collide

Browser clone of the Block Collide puzzle game. Click blocks so they slide along their paths without crashing into each other. Clear the level when every block has finished moving.

Play: https://sriv95.github.io/Block-Collide/

## Development

Needs [Bun](https://bun.sh).

```sh
bun install
bun run dev      # Vite dev server, http://localhost:5173
bun run build    # tsc + vite build -> dist/
bun test         # level and solution checks
```
